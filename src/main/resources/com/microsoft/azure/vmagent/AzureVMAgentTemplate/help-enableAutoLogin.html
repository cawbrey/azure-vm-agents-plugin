Windows agents only. Configures the VM to automatically log on as the admin user, using additionalUnattendContent. This is useful when agents need an interactive desktop session, e.g. for UI tests.

Requires username/password admin credentials and a generalized image. Specialized images are not supported.

First Logon Commands are run the first time the admin user logs on (Windows FirstLogonCommands), in the order listed. Each command is run as-is, so it must be directly executable, e.g. cmd.exe /c .... Each command is limited to 1024 characters and all commands combined must fit in Azure's 4 KB unattend content limit.
